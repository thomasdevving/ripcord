4:25–5:10 · Mobula implementation
“The core report finishes first. Mobula then adds a separate, opt-in second layer. It proposes every asset identity from the fresh holdings response—not only the priced top twelve. Ripcord selects up to sixty-four same-chain ERC20s, verifies their code and target balance at the pinned block, and itemises anything it excludes. For Compound, even a verified zero-balance candidate can continue: Ripcord asks Compound whether it is registered collateral, seeds an isolated holder only inside Anvil, executes the real approve, supply and withdraw paths, then repeats the exit after the guardian pause. Every asset gets its own snapshot. The final composer accepts the sidecar only when target, chain, block number and block hash match. Confirmed evidence can broaden the finding, but Mobula never rewrites or softens the deterministic verdict.”
