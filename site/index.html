What these pages are

Each page is rendered from a pinned JSON report — no live scanning, no network access at render or view time. Only reports that pass the disclosure gate are published here; reports blocked by an unrecognised probe result are deliberately absent.

Read the colours as epistemics, not as grades. Amber is not "medium risk" — it means Ripcord could not establish an answer, and an unestablished answer is never rendered as a pass. A hatched bar has no length to read off it on purpose.
